# Blood, Sweat and Code (IntelliJ)

A fan-made BTS-themed coding companion for JetBrains IDEs. Not affiliated with HYBE or BTS. Inspired by Ridiculous Coding.

- **Sweat** = keystrokes, **Blood** = bugs squashed, **Code** = lines written vs your daily goal
- Typing: pastel hearts + Jimin laugh/sing. Deleting: "7" burst + Jungkook/mic drop. Goal hit: confetti + chicken noodle soup.
- Easter eggs: type `borahae`, `army`, `bts`, `jimin`, ...
- Calm mode turns off effects and sound, counts keep going.

## Build / run
```
./gradlew runIde         # test in a sandbox IDE
./gradlew buildPlugin    # zip in build/distributions/
./gradlew verifyPlugin   # compatibility check
```
Needs JDK 21. See PUBLISHING.md to release.
